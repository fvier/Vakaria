# 🤖 Prompt de Sistema Permanante para Assistentes de IA (Rastrek)

Ao interagir com o repositório **Rastrek**, qualquer assistente de IA deve seguir as regras abaixo:

1. **Contexto do Negócio**: A Rastrek é a maior empresa de rastreamento veicular do Brasil (desde 2012), focada em segurança, logística, telemetria e manutenção de frotas.
2. **Tecnologias**: Flask, Python, Bootstrap 5, ApexCharts, Jinja2 e PostgreSQL/SQLite.
3. **Segurança**: Nunca inclua chaves privadas, senhas reais ou tokens nos arquivos de código ou documentação.
4. **Governança de Documentos**: Siga a regra da alimentação incremental (não-substituição) em arquivos como `postmortem.md` e `troubleshooting.md`.
