# 💈 Vakaria - Barbearia

Projeto web da barbearia **Vakaria**. Uma plataforma moderna para apresentação de serviços, equipe de barbeiros, agendamentos e contato com os clientes.

---

## 📌 Sobre o Projeto

O **Vakaria** foi pensado para oferecer uma experiência digital sofisticada e ágil para clientes de barbearia:
- Catálogo de serviços (corte de cabelo, barba, tratamentos capilares, acabamentos).
- Perfil e especialidade dos barbeiros.
- Sistema de agendamento e integração com WhatsApp.
- Localização, horários de funcionamento e avaliações de clientes.
